# O Intervalo — edição editorial

## Arquivos
- `index.html`: conteúdo, estrutura e metadados.
- `style.css`: identidade visual, layout responsivo e estados visuais.
- `script.js`: menu, filtros, busca, navegação, animações, progresso de leitura e tratamento de imagens.

## Imagens locais
Adicione à pasta `imagens/` os arquivos `montanha.jpg`, `mar.jpg`, `interior.jpg` e `carruagem.jpg`. Se faltar uma imagem, o site mostra um fallback visual.

Use imagens próprias ou confirme a licença antes de publicar. Os links de ensaios apontam provisoriamente para o canal; substitua cada um pela URL do vídeo correspondente quando estiver disponível.

## Abrir
Abra `index.html` no navegador. Para desenvolver, recomendo a extensão Live Server do VS Code.
